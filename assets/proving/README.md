# Pinned Tornado proving assets

The circuit and key compressed files come from the published `tornado-ui-new-era/dist/offline/proving` asset set. The native Lean prover worker reads them through `WithdrawProof.loadAssets` and the Classic proof pipeline. It authenticates the compressed bytes, decompresses them in Lean, checks the raw hashes and circuit/key structure, constructs the witness, and verifies the generated proof with the compiled Classic key.

- `tornado-3ddd61dbff09caee.json.gz`: 19,474,889 bytes decompressed; SHA-256 `3ddd61dbff09caeec82d8edde95c674a3c34f9e66b1fe9f2c8783e72fe536f98`.
- `tornadoProvingKey-8e2d2f22beafb5a9.bin.gz`: 14,522,256 bytes decompressed; SHA-256 `8e2d2f22beafb5a9666daebca57b13f8029c3656c65fcfbcc86e2418fa16a3af`.

The exact compressed/raw hashes and sizes are pinned and checked by [`scripts/verify.mjs`](../../scripts/verify.mjs). The independent [public proof fixture](../../fixtures/groth16-full-public-proof.json) and its [generator](../../scripts/generate-full-public-proof.mjs) retain the reference source and proving-key identities. The worker also requires the authenticated graph at `fixtures/witness-vm-selected-components.json`, relative to its proving-assets root.

`assets/proving/tornado-witness-certificate-v1.json.gz` is a separate public
arithmetic derivation certificate generated by `scripts/build-witness-certificate.mjs`.
It is 1,230,423 bytes compressed (SHA-256
`a2f7ad681ace3416a047ca5483c5590a54c2e71a7e368005e2c0f65dd642559e`),
8,881,780 bytes decompressed (SHA-256
`4ff381811f67b8703f6edae8782d896979b30feef1a71bd198c103163c02d0f8`).
It contains no private witness. Its extractor is untrusted: the native
public-data gate independently recompiles the 76,676-node DAG, regenerates
local equations, verifies linear elimination against every pinned R1CS row,
checks actual native generator/subgroup and circuit-base bindings, and checks
the full independent signed-window point schedule. Only erased derivation
facts and six public generator coordinates survive admission. No expanded
DAG or derivation transcript is retained alongside secret computations.
This gate runs before the isolated worker reads the spendable note or entropy.

Public, unfunded fixtures exercise native proof generation and byte-for-byte
SDK compatibility. These asset hashes do not establish setup honesty,
deployed-verifier identity, constant-time execution or secret erasure.
